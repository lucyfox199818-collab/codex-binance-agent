## 评论回复模板

### “能保证赚钱吗？”

不能。项目不承诺收益，重点是 MCP 工具、风险门禁、dry-run 和可审计执行。任何策略
都可能亏损，尤其是合约和杠杆交易。

### “没有 Binance key 能试吗？”

可以先读取公共行情并保持 dry-run。账户、持仓和私有订单数据才需要 API key。

### “为什么不做成无人值守机器人？”

当前设计刻意让交易决策留在活跃的 Codex 会话中，并要求执行前检查与执行后复核，
避免把模型直接包装成缺少监督的后台交易服务。

### “如何报告问题？”

请在 GitHub Issue 中附操作系统、Node.js 版本、Codex 版本、执行步骤和脱敏后的错误
信息，不要上传 `.env`、API key、secret、账户余额或完整订单隐私。
