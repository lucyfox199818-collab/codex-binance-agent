不是一段“帮我炒币”的提示词

项目把模型判断、工具权限、执行结果和复盘记录拆成明确组件， 让关键状态可以读取、验证和追踪。

CCXT MCP

市场、账户与订单工具

覆盖行情、持仓、成交、普通订单、条件单、保护单、资金费率和 Binance USDT-M 公共情绪数据。

LOCAL SKILLS

三套有边界的交易流程

V1 单轮扫描、V2 当前会话连续决策、V3 自由裁量研究，各自具有策略文件、门禁与审计纪律。

AUDIT

全链路本地审计

SQLite、JSONL、压缩 payload blob 与 hash chain 保存每轮策略、数据、决策、风险、执行和复核。

SAFETY

默认 Dry-run

真实交易需要显式打开双开关。审计工作台只读，不提供下单、撤单、转账或提现按钮。

架构

Codex CLI → project-local skills → ccxt-mcp → exchange
decision → risk gate → action → verification → local audit

先从公共行情和 Dry-run 开始

ccxt-mcp 已发布为公开 OCI 镜像，并进入官方 MCP Registry。 不配置 API key 也可以先使用公共行情能力。 

docker run --rm -i \
  -e CCXT_ENABLE_TRADING=false \
  -e CCXT_DRY_RUN=true \
  ghcr.io/lucyfox199818-collab/ccxt-mcp:0.1.0
查看 Registry 记录 完整安装文档

风险边界

本项目是开源工程与交易自动化实验，不构成投资建议，不承诺收益。 合约和杠杆交易可能快速损失本金。请先使用公共行情、Dry-run 或测试环境， 并为真实账户使用独立、低权限、禁用提现且绑定 IP 白名单的 API key。
