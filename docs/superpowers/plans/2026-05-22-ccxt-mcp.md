# CCXT MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone `ccxt-mcp` MCP server that exposes CCXT market-data and trading capabilities to Codex, reads proxy and Binance credentials from `.env`, and can be packaged as a Docker image.

**Architecture:** A TypeScript Node.js MCP stdio server wraps CCXT exchange instances through a focused adapter. Curated MCP tools cover common workflows, while a generic `ccxt_call` tool exposes the wider CCXT method surface when the method exists on the selected exchange.

**Tech Stack:** Node.js 22, TypeScript, Vitest, `@modelcontextprotocol/sdk`, `ccxt`, `zod`, `dotenv`.
